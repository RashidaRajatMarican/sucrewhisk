# Sucre Whisk Ordering App

A simple mobile-friendly frontend ordering app with:
- Gelato, granola and drinks
- Shopping cart
- Pickup date and time
- Customer details
- GST calculation
- Demo checkout
- Order confirmation
- Pink and white branding

## Run it
Open `index.html` in a browser.

## Real payments
The current payment button is a demo. For production, connect Stripe, HitPay, Adyen or a PayNow-supported gateway.

## Recommended production upgrade
Add Supabase or Firebase for orders, customers, product availability, pickup slots and an admin dashboard.

## Sucre Whisk visual theme
The app uses a soft pink branded background, translucent product cards and pink accents. Add `images/gelato-making.png` to use the generated Sucre Whisk artwork as the hero/background image.
